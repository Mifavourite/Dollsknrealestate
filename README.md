# Doll SKN Real Estate Agency

A 10-page website for **Adolceen Letisha Woodley** and **Doll SKN Real Estate Agency** — St. Kitts & Nevis.

## Pages

1. **Home** (`index.html`) — Hero, featured listings, about preview, services
2. **About** (`about.html`) — Agent bio and company values
3. **Buy** (`buy.html`) — Properties for sale
4. **Rent** (`rent.html`) — Rental listings
5. **Property Detail** (`property.html`) — Individual property page
6. **Services** (`services.html`) — Buy, sell, rent, and advisory services
7. **Neighborhoods** (`neighborhoods.html`) — St. Kitts & Nevis area guide
8. **Testimonials** (`testimonials.html`) — Client reviews
9. **Contact** (`contact.html`) — Contact form and office info
10. **License** (`license.html`) — Official business licence credentials

## Run Locally

Open any HTML file in a browser, or serve with a local server:

```bash
npx serve .
```

Then visit `http://localhost:3000`

## Customize

- Update contact details in `js/main.js` (`SITE` object)
- Edit property listings in `js/main.js` (`PROPERTIES` array)
- Replace Unsplash placeholder images with real photos
